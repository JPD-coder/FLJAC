UPLOAD TO GITHUB
================

Upload BOTH of these files to your repository:

    index.html
    rules.html

That is the entire website. Nothing else goes to GitHub.

There is no assets folder and no .nojekyll file needed - every image is
embedded inside the two HTML files.

HOW
---
1. In your repo: Add file  ->  Upload files
2. Drag in index.html and rules.html
3. Commit changes
4. Wait 30-60 seconds, then hard-refresh the site
   (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)

Your site: https://jpd-coder.github.io/FLJAC/
The rules page will be at /rules.html

DO NOT open these files in GitHub's built-in text editor. The embedded
images make the lines very long and the editor will struggle. Uploading
is fine. If you need a text change, ask and a new file will be made.
